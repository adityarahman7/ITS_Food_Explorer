# ITS Food Explorer

Prototipe tugas Kewirausahaan Berbasis Teknologi: katalog kuliner sekitar ITS, pencarian AI, dan peta dengan asisten percakapan.

Website: https://adityarahman7.github.io/ITS_Food_Explorer/

Katalog memuat 266 outlet dan 260 menu ilustratif pada sebagian outlet. Menu, harga, dan fasilitas belum tersedia untuk semua tempat.

Frontend statis di GitHub Pages; AI melalui backend Cloudflare Worker terpisah. Repositori publik ini hanya memuat aset website, tanpa secret atau source backend.
